# Боксёрский таймер

Таймер раундов для спаррингов на iPhone. Большие цифры на весь горизонтальный экран, цвет по фазе, голосовой помощник на русском, разные звуки на старт и конец раунда, старт и пауза топотом ногой, настройка голосом.

По умолчанию: **10 раундов × 2:00 бокса / 1:00 отдыха**, 10 секунд подготовки.

## Как открыть на iPhone

1. Открой ссылку GitHub Pages в **Safari**.
2. «Поделиться» → **«На экран Домой»**. Так таймер откроется на весь экран без адресной строки и будет работать офлайн.
3. Нажми **«Включить»** и разреши микрофон или датчик движения. iOS не даёт включить звук и сенсоры без касания, поэтому один тап нужен при каждом запуске.
4. Поверни телефон горизонтально.

## Что происходит во время тренировки

| Момент | Цвет | Звук | Голос |
|---|---|---|---|
| Подготовка | жёлтый | — | «Приготовиться. 10 раундов по 2 минуты» |
| Старт раунда | красный | три высоких «дзынь» | «Бокс!» / «Последний раунд. Бокс!» |
| 10 сек до конца раунда | мигает жёлтым | «тук-тук-тук» | «10 секунд» |
| Последние 3 сек | | короткие бипы | (или счёт «пять… один» вслух) |
| Конец раунда | зелёный | два низких «донг» | «Стоп. Отдых. Осталось 7 раундов» |
| 10 сек до конца отдыха | пульсирует | — | «Десять секунд. Готовимся, раунд 4» |
| Финиш | тёмный | гонг трижды | «Тренировка окончена» |

Все звуки синтезируются в коде, поэтому аудиофайлы не нужны.

## Управление без рук

**Топот** (Настройки → «Старт топотом»):
- **Микрофон** — ловит глухой удар ногой по полу. Телефон можно ставить где угодно рядом.
- **Датчик** — телефон лежит на полу или помосте и чувствует вибрацию. Шум зала не мешает.
- **Оба (строже)** — срабатывает, только если удар и слышно, и чувствуется. Меньше ложных стартов.
- **Двойной топ** (по умолчанию) — два удара подряд в пределах 0,1–0,8 сек. Случайный шаг на него не похож.
- Во время раунда топот по умолчанию игнорируется: в спарринге и так много шагов. Включается отдельным переключателем.
- Внизу настроек есть индикатор: топни и посмотри, срабатывает ли. Чувствительность настраивается ползунком.

Топот при остановленном таймере — старт. На паузе — продолжить. Во время отдыха — пауза.

**Голос** (кнопка «голосом»): скажи, например:
- «10 раундов по 2 минуты, отдых минута»
- «12 раундов по 3 минуты, отдых 30 секунд»
- «2 минуты бокс, 1 минута отдых, 8 раундов»
- «подготовка 15 секунд», «предупреждение за 15 секунд»

**Голосовые команды** (бета, в настройках): «старт», «пауза», «продолжить», «дальше», «сброс». Микрофон на iPhone один, поэтому вместе с командами топот работает через датчик. Пока говорит сам таймер, команды не слушаются, чтобы его «Стоп» не ставил паузу.

Тап по экрану — пауза. На паузе доступны «Дальше», «Сброс» и «Настройки».

## Ограничения веб-версии

- **Не блокируй экран.** Веб-страница на iPhone не играет звук при заблокированном экране. Таймер сам держит экран включённым (Wake Lock). Если экран всё равно гаснет: Настройки → Экран и яркость → Автоблокировка → Никогда.
- Если телефон всё же уснул, время не сбивается: при возврате таймер догоняет реальное время.
- Пока включён микрофон (топот через микрофон), iOS может сделать звук чуть тише. Если мешает — режим «Датчик».
- Распознавание речи в режиме «На экран Домой» на некоторых версиях iOS работает хуже, чем в Safari.

Всё это снимается нативным приложением на SwiftUI: фоновый звук, Core Motion, распознавание речи на устройстве. Веб-версия — чтобы быстро проверить идею в зале.

## Разработка

Без сборки: чистые HTML, CSS и JS.

```bash
python3 -m http.server 8000   # http://localhost:8000
```

Клавиши для отладки на компьютере: `Пробел` — старт/пауза, `S` — «топ», `N` — дальше, `R` — сброс.

- `parse.js` — разбор русских фраз в настройки и команды.
- `app.js` — таймер, звук (Web Audio), голос (speechSynthesis), детектор топота, интерфейс.
- `sw.js` — офлайн-кэш.
